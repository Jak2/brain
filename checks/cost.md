# Cost

Whether this is worth what it costs, and what the cheaper version is.

This is the check most often skipped, because it is the only one that can conclude *do
not build this*. Ask it before the sunk cost exists, not after.

## Gets
- The restated request
- What the person said they are trying to achieve, if they said

## Produces
At most **one** question:

1. What is the smallest version that would settle whether this is worth finishing? If
   there is one, name it and say what it leaves out.
2. What does this cost in time, and what happens if it is simply not done? If the answer
   to the second is "nothing measurable," say so plainly.
3. Is there an existing thing here — a helper, a library already installed, a platform
   feature — that covers most of it?

## Forbidden
- Deciding for them. Name the cheaper path and its cost; the call is theirs.
- Refusing to proceed. They reaffirm it, you build the full version without re-arguing.
- Estimating in hours with false precision. "Half a day" and "most of a week" are
  honest; "6.5 hours" is not.
- Raising this on work that is already committed to and underway. The gate runs before.

## Done when
The cheaper version is named, or there genuinely isn't one and you said so.
